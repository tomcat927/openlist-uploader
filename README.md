# Openlist 上传管理器

基于 Tauri + React 的 OpenList 网盘上传管理工具，支持队列管理、定时上传、限速、热更新、系统通知等功能。

## 下载安装

从 GitHub Releases 下载最新安装包：

**https://github.com/tomcat927/openlist-uploader/releases/latest**

下载 `.exe` 安装包，双击安装即可。

### 在线热更新

软件内置自动更新功能：

- **启动时自动检查更新**（设置页可关闭，默认开启）
- 发现新版本弹出对话框，确认后自动下载安装并重启
- 热更新直连 GitHub 加速代理，不走系统代理，不受 Clash 等代理工具影响

## 功能特性

### 上传管理
- **队列管理**：添加、删除、清空上传队列，拖拽添加文件/文件夹
- **重复检测**：相同文件+相同目标路径不会重复添加
- **持久化存储**：程序重启后队列和历史记录不丢失
- **失败重试**：自动重试机制，可配置重试次数
- **历史记录**：按时间排序（升序/降序）、按文件名搜索、按状态筛选（全部/成功/失败）
- **大文件保护**：115 网盘非会员 5GB 文件拦截、4GB 文件风险提示
- **打开文件所在目录**：队列、历史记录、拦截记录均支持定位本地文件

### 上传配置
- **并发数**：同时上传的任务数量（默认 1）
- **最大重试次数**：失败后自动重试次数（默认 5）
- **As-Task 模式**：使用 Alist 后台任务功能（默认启用）
- **上传限速**：通过 AList admin API 控制服务端→云盘上传速度（0 = 不限速）
- **每轮任务数上限**：达到上限后本轮自动停止（0 = 不限）
- **显示进度**：状态列显示上传百分比

### 定时上传
- 设置开始时间和结束时间
- 到达开始时间自动从队列取任务上传，无需手动点「开始上传」
- 到达结束时间等待当前任务完成后自动停止
- 支持定时上传开始/结束时发送飞书通知

### Alist 进程管理
- **自动启动 Alist**：设置页填写 Alist 可执行文件路径，打开本软件时自动启动
- **后台启动**：隐藏控制台窗口（默认开启）
- **退出时关闭 Alist**：退出本软件时同时关闭 Alist 进程（默认开启）
- **测试启动按钮**：设置页可手动测试启动 Alist，轮询 30 秒检测就绪状态

### 代理配置
- **使用系统代理**：默认关闭，本地 Alist 不需要代理
- 远程 Alist 服务器可开启系统代理
- **热更新不走系统代理**：直连 GitHub 加速代理，不受 Clash 干扰

### 通知
- **上传完成通知**：任务完成/失败时发送 Windows 系统通知（设置页可开关）
- **失败飞书通知**：上传失败超过重试阈值时发送飞书 Webhook 通知
- **队列完成飞书通知**：整个队列自然完成时发送飞书通知
- **测试通知按钮**：设置页可测试飞书 Webhook 配置是否正确

### 完成后关机
- **上传完成后关闭电脑**：队列自然完成后自动定时关机（默认延迟 10 分钟）
- 支持自定义延迟分钟数
- 关机前弹窗倒计时，可取消

### 系统托盘
- 最小化到托盘，关闭窗口默认最小化（设置页可配置）
- 托盘图标右键菜单：显示窗口、退出
- 点击托盘图标恢复窗口

## 使用说明

### 基本流程

1. **安装并打开软件**
2. **配置 Alist**（设置页）：
   - 填写 Alist 服务地址（默认 `http://127.0.0.1:5244`）
   - 填写用户名和密码
   - 点击「登录获取 Token」
   - 如需自动启动 Alist，填写 Alist 可执行文件路径
3. **选择目标目录**：在待上传队列页选择 Alist 中的目标目录
4. **添加文件**：点击「选择文件」或拖拽文件到窗口
5. **开始上传**：点击「开始上传」按钮

### 定时上传

1. 设置页 → 启用定时上传
2. 设置开始时间（如 `03:00`）和结束时间（如 `07:00`）
3. 把文件添加到待上传队列
4. 到达开始时间会自动开始上传，无需手动点击
5. 到达结束时间会等待当前任务完成后停止

### 上传限速

1. 设置页 → 上传限速选择速度（0/1/2/5/10 MB/s 或自定义）
2. 限速通过 AList admin API 控制 AList→云盘的上传速度
3. 需要 Alist 管理员权限

### 自动启动 Alist

1. 设置页 → 填写 Alist 路径（如 `E:\system_software\alist\openlist.exe`）
2. 勾选「后台启动 Alist」（隐藏控制台窗口）
3. 勾选「退出时关闭 Alist」
4. 保存配置
5. 可点击「测试启动 Alist」验证路径和启动是否正常
6. 下次打开软件会自动启动 Alist 并等待就绪后自动登录

## 技术栈

- **前端**：React 19 + TypeScript + Vite
- **状态管理**：Zustand
- **桌面框架**：Tauri 2.x
- **后端**：Rust
- **HTTP 客户端**：reqwest

## 数据存储

- **Windows**：`%APPDATA%\openlist-uploader\`（从旧版 `alist-uploader` 升级时自动迁移数据）
- 存储文件：`queue.json`（队列）、`history.json`（历史）、`config.json`（配置）、`blocked_files.json`（拦截记录）

## 开发

# 安装依赖
